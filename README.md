# TODO 任务管理器

一个轻量级离线 TODO 桌面应用，使用 Python + tkinter + SQLite 开发，无需联网，数据存储在本地。

## 功能

- **任务管理** — 新增、编辑、删除、完成任务
- **计时功能** — 对任务进行计时，支持暂停 / 继续，自动累计用时
- **筛选排序** — 按状态筛选（全部 / 待办 / 进行中 / 已完成），按创建时间 / 截止日期 / 用时 / 名称排序
- **清理缓存** — 一键清理 N 天前已完成的任务，并压缩数据库释放空间
- **快捷键** — Ctrl+N 新增、Ctrl+E 编辑、Ctrl+T 开始计时、Ctrl+P 暂停、Ctrl+D 完成、Delete 删除、Ctrl+Q 退出
- **数据持久化** — 关闭程序后计时状态和任务数据自动保存，重新打开恢复

## 运行方式

### 方式一：使用打包好的 EXE（推荐）

下载 `TODOList.exe`，双击运行即可，无需安装任何依赖。

### 方式二：从源码运行

1. 确保已安装 Python 3.9+
2. 确保 tkinter 可用（Windows 版 Python 安装时需勾选 "tcl/tk and IDLE"）
3. 双击 `main.py` 或在终端运行：

```powershell
python main.py
```

无需安装任何第三方依赖库。

### 打包为 EXE

```powershell
pip install pyinstaller
pyinstaller --onefile --windowed --name TODOList main.py
# 生成的 EXE 位于 dist/TODOList.exe
```

## 使用说明

### 新增任务

点击「新增任务」按钮或按 `Ctrl+N`，填写任务名称（必填）、描述、截止日期（格式 YYYY-MM-DD）、预计用时，点击保存。

### 开始计时

选中一个任务，点击「开始计时」或按 `Ctrl+T`。底部状态栏会实时显示当前计时。同时只能对一个任务计时。

### 暂停 / 停止计时

点击「暂停计时」或按 `Ctrl+P` 暂停，用时累积。再次开始计时会从中断处继续。完成任务时会自动停止计时。

### 完成任务

选中任务，点击「完成任务」或按 `Ctrl+D`。

### 清理缓存

点击「清理缓存」，设置要删除多少天前已完成的任务，点击执行清理。同时会自动压缩数据库。

### 筛选和排序

使用工具栏下拉框筛选任务状态和排序方式。

## 数据存储

所有数据存储在程序目录下的 `data/todolist.db` SQLite 数据库文件中。删除此文件可重置所有数据。
